MedCalc is statistical software for biomedical research. The version 24.0.4 Windows installers are offered as a 15-day trial with full features and no registration during the trial.

- [GitHub Pages product page](https://medcalcsoft.github.io/medcalc/)
- [GitHub repository](https://github.com/MedCalcSoft/medcalc)
- [Release and download](https://github.com/MedCalcSoft/medcalc/releases/tag/24.0.4)

## Package

The ZIP release includes the original 32-bit and 64-bit Windows setup EXEs, installation notes, a licensing notice, SHA-256 checksums, and the website source archive. The setup files are unchanged from the downloaded vendor files; their Authenticode signatures and hashes are recorded in the package.

- `medcalcsetup32.exe` works on 32-bit and 64-bit Windows.
- `medcalcsetup64.exe` requires 64-bit Windows.
- The trial lasts 15 days; after the trial, a license is required to continue using the software.

The software is proprietary. This GitHub release is a redistribution package, not the software publisher's website or a software source-code repository. Distribution permission was confirmed by the repository owner.
